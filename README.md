# 마이미라운지 MY · ME LOUNGE

상수·홍대 **마이미 호텔 감성**의 라운지 카페 랜딩페이지입니다.

## 실행

```bash
npm install
npm run dev
```

[http://localhost:3000](http://localhost:3000) 에서 확인할 수 있습니다.

## 기술 스택

- Next.js (App Router) + TypeScript
- Tailwind CSS + shadcn/ui
- Framer Motion
- Pretendard + Cormorant Garamond
